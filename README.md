📚 Intelligent Library Book Tracking System

An intelligent PHP–MySQL based system to manage library books, users, and borrow history with secure CRUD operations and a clean UI.

🚀 Features

Add, update, delete, and view books

Add and manage users

Assign/return books (student → book mapping)

Real-time success & error messages

Secure database operations (prepared statements)

Search & filter options

Simple and clean UI design

🛠️ Tech Stack

Frontend: HTML, CSS

Backend: PHP

Database: MySQL

Server: XAMPP / Apache

📂 Project Structure project/ │── index.php │── db.php │── add_book.php │── add_user.php │── assign_book.php │── update.php │── delete.php │── view_books.php │── view_users.php │── assets/ │ └── css/ │ └── images/ │── sql/ │ └── library.sql

📥 Installation

Download or clone the project

Copy project folder into htdocs

Import sql/library.sql into phpMyAdmin

Update DB credentials in db.php

Run the project in browser:

http://localhost/project-folder/
